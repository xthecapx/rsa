Third-party art used by the game
================================

city_tiles.png
--------------
Kenney "Roguelike Modern City" (2.0), file Tilemap/tilemap_packed.png
https://kenney.nl/assets/roguelike-modern-city
37 x 28 grid of 16x16 tiles, no spacing.

portraits.png
-------------
Kenney "Roguelike Characters", file Spritesheet/roguelikeChar_transparent.png
https://kenney.nl/assets/roguelike-characters
54 x 12 grid of 16x16 tiles, 1px spacing between tiles.

Both are Creative Commons Zero (CC0):
http://creativecommons.org/publicdomain/zero/1.0/
Free to use in personal, educational and commercial projects.
Created and distributed by Kenney (www.kenney.nl).


characters.png
--------------
NOT a Kenney asset. Kenney's character pack ships front-facing busts rather
than four-direction walk cycles, so the overworld sprites are generated by
tools/gen_characters.py in the same 16x16 pixel style. Re-run that script to
change the cast's colours or silhouettes.


icons/locked.png
----------------
Kenney "Game Icons", file PNG/White/2x/locked.png
https://kenney.nl/assets/game-icons
Used as the source glyph for the PWA / home-screen icons under public/icons/
(regenerate with tools/gen_pwa_icons.py). CC0 — see icons/LICENSE.txt.


ui/
---
Kenney "UI Pack" (2.0) — selected PNG buttons, dividers, inputs and slides.
https://kenney.nl/assets/ui-pack
Used for the boot splash, mute control and loading chrome. CC0.


audio/
------
Kenney audio packs (CC0), trimmed to the clips the game actually plays:

  music/mission-plausible.ogg, infinite-descent.ogg
    Kenney "Music Loops" — Mission Plausible, Infinite Descent
    (legacy Music Loops pack; same Kenney CC0 terms)

  jingles/intro.ogg, win.ogg, lose.ogg
    Kenney "Music Jingles" — 8-Bit NES00 / NES07 / NES03
    https://kenney.nl/assets/music-jingles

  sfx/click.ogg, switch.ogg, rollover.ogg
    Kenney "UI Audio"
    https://kenney.nl/assets/ui-audio

  sfx/confirm.ogg, error.ogg, select.ogg
    Kenney "Interface Sounds"
    https://kenney.nl/assets/interface-sounds

  sfx/computer.ogg
    Kenney "Sci-Fi Sounds" — computerNoise_000
    https://kenney.nl/assets/sci-fi-sounds
